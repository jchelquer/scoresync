{% translate "Cómo armar una obra" %}

{% translate "Acá se junta todo lo que hace falta para poder practicar: el audio de referencia, las partes (partituras) y la configuración de itinerario/notación de cada una." %}

{% translate "Publicada" %}

{% translate "Una obra despublicada sólo la ven el dueño y los admins. Para poder publicarla hace falta un itinerario armado, al menos una parte con los compases confirmados, y la temporización por compases completa en \"Sincronizar compases\"." %}

{% translate "Itinerario, Notación y Sincronizar compases" %}

{% translate "Los tres pasos para preparar la ejecución: el orden de los compases, los datos de la partitura (tempo/armadura/indicación), y la temporización real contra el audio." %}

{% translate "Partes" %}

{% translate "Cada parte es una partitura (PDF) de un instrumento. \"Cargar parte\" sube una nueva; \"Adjuntar parte suelta\" suma una que ya subiste para otra obra o quedó huérfana. Sólo el dueño de cada parte puede editarla, separarla (queda suelta, sin borrarla) o borrarla." %}

{% translate "Borrar la obra no se puede deshacer — hay que escribir el título exacto para confirmar." %}
