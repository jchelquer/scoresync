{% translate "Cómo armar el Itinerario" %}

{% translate "El itinerario se usa para saber en qué orden se debe ejecutar la obra. Cada fila es un tramo de compases que se toca de corrido, en el orden real de ejecución." %}

{% translate "Numeración de filas" %}

{% translate "Es un método sencillo para insertar filas o reordenarlas. Cada fila recibe un número (preferentemente de 10 en 10) y cuando hace falta cambiar una de lugar basta con ponerle un número acorde y guardar. Las filas marcadas con la casilla" %} {% translate "Borrar" %} {% translate "se eliminan al guardar." %}

{% translate "Cuando hay bloques repetidos o saltos (2da vez, D.C., al Segno, a Coda, etc.) simplemente se indica en una nueva fila por dónde debe seguir la ejecución secuencial." %}

{% translate "Desde / Hasta" %}

{% translate "Normalmente es un número de compás entero (p.ej. 20), pero puede indicarse un pulso dentro del compás (p.ej. 20,2 es el pulso 2), incluso una fracción de pulso (20,2.5 sería el pulso 2 y medio del compás 20)." %}

{% translate "Tiempo calculado" %}

{% translate "Es una estimación a partir del tempo cargado en Notación — se recalcula solo al guardar, es sólo de referencia hasta que se sincronice con audio real (ver \"Sincronizar compases\")." %}

{% translate "La indicación de compás, el tempo base y los efectos de tempo (accelerando/ritardando/calderón) no se cargan acá — son hechos de la partitura por posición, se cargan una sola vez en Notación." %}
